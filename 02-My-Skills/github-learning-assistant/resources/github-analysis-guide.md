# GitHub Repository Analysis Guide


## 1. Repository Overview

Analyze:

- Project name
- Author
- Description
- Stars
- Forks
- Last update


## 2. Project Structure

Check:

- README.md
- Main folders
- Source code
- Documentation
- Examples


## 3. Technology Identification

Identify:

- Programming languages
- Frameworks
- AI models
- Agent frameworks
- Database systems


Examples:

- Python
- JavaScript
- PyTorch
- LangChain
- LlamaIndex
- RAG
- MCP
- Vector Database


## 4. Learning Analysis

Generate:

- Project overview
- Core concepts
- Important files
- Technical architecture
- Learning points
- Next steps


## 5. Output Principle

The final analysis should help an AI engineering student understand:

- What the project does
- How the project works
- Which technologies are used
- How to learn from the project
